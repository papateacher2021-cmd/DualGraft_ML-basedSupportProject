# 🧬 Sistema de Apoyo a la Decisión Clínica: Trasplante Dual Graft

Plataforma predictiva basada en **Redes Neuronales Profundas (PyTorch)** y **Streamlit** para estimar la probabilidad de éxito de tolerancia inmunológica y supervivencia en trasplantes.
